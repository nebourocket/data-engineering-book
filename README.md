# The Data Engineering Book

**A free, hands-on book that takes you from zero to a job-ready data engineer.**
Read it online: **https://nebourocket.github.io/data-engineering-book/**

The book is written in Japanese first; English and Chinese editions are in progress (the site will let you switch languages).
Author: Nebou Rocket (寝坊ロケット).

## What you will learn

| Part | Price | Contents |
| --- | --- | --- |
| **Basics** (16 chapters) | Free | What data engineering is, how computers store data, Linux / shell / Git, Python for data work, SQL from the ground up (incl. window functions and query plans), relational databases and transactions, dimensional modeling (star schema, SCD), ingestion (APIs, files, CDC basics), ETL/ELT with dbt, data warehouses, orchestration with Airflow, data quality, cloud / Docker / object storage, streaming with Kafka, and an end-to-end capstone project and career guide |
| **Advanced** (12 chapters) | One-time purchase (JPY 500) | Distributed processing internals and Spark tuning, lakehouse table formats (Delta / Iceberg), streaming design (exactly-once, watermarks), CDC and event-driven architecture, large-scale modeling, data contracts, observability and lineage, governance and privacy, cost optimization, data platforms for ML/AI, platform design and organization |

Every chapter follows the same structure: goals, theory and background, how it works, hands-on exercises, common mistakes, summary, practice problems with answers, and references.

## How this book is built

- **Every code sample is tested.** Each code block in a chapter is a verbatim excerpt of a file under `examples/`, and `pytest` runs those files. A checker (`hooks/chapter_check.py`) fails the build if a block in the text drifts from its tested source or is cut mid-function.
- **One running example.** All chapters use the same fictional online shop, "Neboske Shop" (`examples/common/neboske_shop.py`), generated deterministically with `seed=42`. It contains intentional data-quality defects (duplicates, nulls, late events) for the quality chapters.
- **No hand-typed tables or numbers.** Tables are rendered from CSV files in `data/tables/`, and charts are generated by scripts in `examples/figures/` at build time.
- **Real services, locally.** PostgreSQL, MinIO (S3-compatible) and Redpanda (Kafka-compatible) run via `compose.yaml`; CI runs the same services and fails if any service-backed test is skipped.
- **Facts are sourced.** Each chapter cites official documentation, RFCs, papers or books, and every chapter goes through a fact-check and an editorial review before it is published.

## Run it yourself

Requirements: Docker (on Windows, use WSL 2).

```bash
git clone https://github.com/nebourocket/data-engineering-book.git
cd data-engineering-book
docker build -t de-book-dev .
alias DEV='docker run --rm --user "$(id -u):$(id -g)" -e HOME=/tmp -v "$PWD":/w -w /w de-book-dev'

DEV mkdocs build --strict                         # build the site into site/
docker run --rm -p 8000:8000 -v "$PWD":/w -w /w de-book-dev mkdocs serve -a 0.0.0.0:8000   # preview at http://localhost:8000
DEV pytest                                        # run all tests (service tests are skipped)
```

To run the service-backed examples (chapters 7, 9, 14, 15 and others):

```bash
docker compose up -d --wait
docker run --rm --network host --user "$(id -u):$(id -g)" -e HOME=/tmp \
  -e PG_DSN=postgresql://deb:deb@localhost:5432/deb \
  -e S3_ENDPOINT=http://localhost:9000 -e S3_ACCESS_KEY=minioadmin -e S3_SECRET_KEY=minioadmin \
  -e KAFKA_BOOTSTRAP=localhost:19092 -e DE_BOOK_REQUIRE_SERVICES=1 \
  -v "$PWD":/w -w /w de-book-dev pytest
docker compose down
```

`DE_BOOK_REQUIRE_SERVICES=1` turns a missing service into a test failure instead of a skip (CI uses this). The MinIO image is a pinned legacy build (`bitnamilegacy/minio`) because the official image is no longer distributed; use it for local learning only.

## Repository layout

```
book/              Chapters (Markdown). basics/ is free; advanced/ holds only the chapter introductions
examples/          Tested code for every chapter (examples/bNN/), shared data generator (common/), figure scripts (figures/)
data/tables/       CSV sources of the tables shown in the book
hooks/             MkDocs hooks: CSV tables, figure generation, chapter checker
tests/             Checks for chapters, hooks and the paid-content leak guard
worker/            Cloudflare Worker that issues purchase keys and serves the advanced chapters
docs/              Design spec, implementation plans, chapter writing guide, deployment guide
```

## How the paid part works

The advanced chapters are **not** in this repository. They live in a private repository and are served from Cloudflare Workers KV. After a Stripe checkout, the Worker (`worker/`) verifies the payment and returns an ECDSA-signed key; the page sends that key to fetch each chapter. A leak check (`tests/check_no_paid_text.py`) makes sure no paid text ends up in this public repository or the built site. See [docs/DEPLOY.md](docs/DEPLOY.md).

## Notes for AI agents working on this repository

- Never put advanced (paid) chapter text in this repository, not even in tests or examples.
- Do not hand-type tables in chapters; use `data/tables/*.csv` with `{{ table("name") }}`.
- Read `docs/CHAPTER_GUIDE.md` before writing a chapter; `pytest` (tests/test_chapters.py) enforces it.
- Secrets live only in `wrangler secret`; never commit them.
