# CDC とイベント駆動

業務のデータベースで起きた変更を、ほかのシステムへ確実に届けたい。この要望は、データ基盤の現場でとても多く聞かれます。この章では、変更を取り出す CDC の仕組みと、Debezium でログから変更を読む流れを説明します。さらに、データベースの更新とメッセージの送信を食い違わせないための outbox パターンを紹介します。二重送信や順序の入れ替わり、削除の伝え方など、つまずきやすい点も具体例で確かめます。定期的に全件を取り直す方法と比べて、どこが良くなるのかを判断できるようにします。
