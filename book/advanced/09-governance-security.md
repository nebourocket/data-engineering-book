# ガバナンス・セキュリティ・個人情報

データを集めて使えるようにするほど、誰が何を見てよいかを決める責任も重くなります。この章では、権限の与え方、列や行の見え方を変えるマスキング、あとから調べられる監査ログといった技術的な守りを整理します。あわせて、個人情報保護法の要点を、設計に関わる範囲でやさしく解説します。何を個人情報として扱い、どこまで保存し、いつ消すのかを、基盤の側からどう支えるかを考えます。法律の専門家の代わりにはなりませんが、相談すべき点に気づける設計者になることを目指します。
