# データエンジニアの本

著者: 寝坊ロケット

## この本の目的

データを集めて、整えて、使える形で届ける仕事（データエンジニアリング）を、基礎から応用まで順番に学ぶための本です。仕組みを先に説明し、そのあとに手を動かします。

## 読み方

- プログラムを書いたことがない方は、準備編（8 章）から読み始めてください。
- Python と SQL を書ける方は、基礎編（16 章）から読めます。最初から順に読むのがおすすめです。
- 応用編は 12 章。基礎編を終えたあと、気になる章から読めます。
- 各章は「できるようになること」から始まり、まとめと練習問題で終わります。
