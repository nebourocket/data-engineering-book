# 準備編

プログラムを書いたことがない人が、基礎編を読み始められるようになるための 8 章です。無料で読めます。

## 誰のための編か

- パソコンは使えるが、ターミナル（文字でパソコンに命令する画面）を使ったことがない人。
- Python（プログラミング言語）や SQL（データベースに問い合わせる言語）を、まだ書いたことがない人。
- 独学で挫折したことがあり、最初の一歩を細かく確かめながら進みたい人。

すでに Python と SQL を書ける人は、この編を飛ばして基礎編から読めます。

## 進め方

- 第 1 章から順に読みます。後ろの章は、前の章で覚えたことを使います。
- 本文のコードは、読むだけでなく自分の手で打ってください。打つ、画面にどう出るかを見る、何が起きたかを確かめる、の順で進みます。
- 打ち間違えてエラーが出ても大丈夫です。つまずきやすい所は先に書いてあり、第 8 章には困ったときの進み方をまとめています。
- 各章の終わりに練習問題が 5 問以上あります。解答例は隠してあるので、先に自分で考えてください。
