# 準備編と多言語化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. 執筆の流れ・検査・文体は `2026-11-13-writing-the-book.md` と `docs/CHAPTER_GUIDE.md` に従う。

**Goal (2026-11-14 ユーザー指示):** プログラミングも SQL も初めての人が最初から読める「準備編」を足し、基礎編・応用編とあわせて「これ1冊でデータエンジニアリングを網羅」する。サイトを日本語・英語・中国語 (簡体字) で切り替えられるようにする。

**Architecture:**
- 準備編は `book/start/` に置く無料の8章 (章 ID `s01`〜`s08`、examples は `examples/s01/`〜)。nav は「はじめに / 準備編 / 基礎編 / 応用編 / 特定商取引法に基づく表記」。
- 多言語化は `mkdocs-static-i18n` (suffix 形式: `page.md` が日本語、`page.en.md`・`page.zh.md`)。Material の言語切り替えを出す。既定は日本語。
- 表は `data/tables/<lang>/` (日本語は今の `data/tables/`)。hook がページの言語で選ぶ。図のスクリプトはラベルを言語ごとの辞書で持ち、`book/assets/figures/<lang>/` に出す。
- コード (`examples/`) は全言語で共通。コード内のコメントは日本語のまま (翻訳版の本文で一言断る)。
- 応用編: KV のキーを `chapter:<ID>:<lang>` に、Worker の `/chapter/<ID>?lang=en|zh|ja`、`pro.js` がページの言語を渡す。価格・キーは言語によらず共通。

**翻訳の方針:** 日本語版の章が仕上がってから訳す (二度手間を避ける)。翻訳は執筆役が行い、別の役が原文と照らして確かめる。翻訳の検査 (自動): 見出しの数と並び・コードブロックが原文と完全に同じ・`{{ table() }}` の名前が同じ・参考文献の数が同じ・練習問題と解答の数が同じ。長さの検査は日本語版だけ。

## Global Constraints

- 準備編の読者は「プログラムを書いたことがない人」。専門用語は使う前に必ず説明し、1つの節で新しい考え方は1つ。手順は「打つ → 画面にこう出る → 何が起きたか」の順。つまずきやすい所 (全角スペース・大文字小文字・保存し忘れ・パス) を先回りして書く。
- 準備編の長さ: 1章 8,000〜16,000 字 (目標 10,000〜13,000)。練習問題は5問以上、すべて解答例つき。
- 基礎編の第4章 (Python)・第5章 (SQL) の冒頭に「初めての人は準備編 第N章から」の案内を入れる。
- それ以外は既存の Global Constraints (表は CSV、本文のコードは examples の丸ごとの写し、出典、名義 寝坊ロケット、有料本文を公開側に入れない) のまま。
